# HR-Analytics-Dashboard-Tableau
The **HR Analytics Dashboard** is an interactive Tableau dashboard designed to analyze employee workforce data and provide meaningful insights into employee attrition, demographics, departments, education, job satisfaction, and age groups.
The dashboard transforms raw HR data into an easy-to-understand visual report that can help HR teams and management identify workforce trends, understand employee attrition patterns, and support data-driven decision-making.
## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall employee workforce statistics.
- Understand employee attrition patterns.
- Compare attrition across different departments.
- Analyze attrition by gender.
- Understand attrition across different age groups.
- Analyze education field-wise attrition.
- Understand job satisfaction across different job roles.
- Compare active employees and employees who have left the organization.
- Provide an interactive dashboard for HR decision-making.
